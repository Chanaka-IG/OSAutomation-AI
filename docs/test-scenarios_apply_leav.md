# Test Scenarios: Apply Leave (ESS)

> Feature: An Employee Self-Service (ESS) user applies for their own leave at `/leave/applyLeave`.
> Source: `orangehrm-opensource-domain` (business-rules §4 Leave Workflow, §5 Entitlements; user-flows Flow 4).
> Generated by `/create-scenarios`. Consumed by `/test-strategy`.

Key domain facts:
- ESS applies for **their own** leave only — the Apply page has **no employee selector** (unlike Admin Assign Leave).
- Applied leave gets status **Pending Approval** (code 1), not Scheduled.
- Balance is `entitlement - (scheduled + taken + pending)`; the **pending portion is held in escrow** (deducted immediately on apply).
- `numberOfDays` excludes weekends/holidays per the Work Week.
- Overlapping a non-cancelled request → `"Overlapping leave requests found"`.
- Applying without entitlement / over balance → blocked (`"Leave balance exceeded"` / balance shows insufficient).
