## Contested Calls

- **TC-006 → P0**: arguably "just a widget", but it is the only dashboard element that
  *drives* a workflow (approvals). A regression delays leave approvals org-wide and is
  invisible until someone complains — classic silent P0.
- **TC-002 → P0 vs TC-003/TC-004 → P1**: one tile at P0 proves the launcher wiring
  mechanism end-to-end; the remaining tiles are the same mechanism with different
  targets — high impact but mechanically redundant, so P1.
- **TC-007 → P1 not P0**: prominent and universal, but informational — wrong punch text
  doesn't block any action and attendance has its own module coverage.
- **TC-301 → P2**: valuable resilience check, but mocked-failure scenarios are not
  release-blocking for a stable instance and the blast radius of the bug is a degraded
  (not broken) dashboard.
