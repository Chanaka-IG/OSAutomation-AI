> Input: `docs/test-strategy.md` (E2E-assigned scenarios). Generated by `/define-priority`. Consumed by `/generate-tests`.

## P0 — Release-Blocking (core flow, security, data integrity, no workaround)
| ID | Title | Rationale |
|----|-------|-----------|
| TC-001 | ESS applies for a full-day leave with sufficient balance | Core happy path — the entire feature is dead if this fails |
| TC-105 | Applied leave status is "Pending Approval" (not Scheduled) | Data integrity — wrong entry state breaks the approval workflow downstream |
| TC-201 | Unauthenticated access to Apply Leave redirects to login | Security — no leave application without authentication |
| TC-202 | Apply page has no employee selector for ESS (self-only) | Security/data isolation — ESS must not apply on behalf of others |
| TC-304 | Overlapping leave request is rejected | Data integrity — duplicate/overlapping leave corrupts balances and schedules |
