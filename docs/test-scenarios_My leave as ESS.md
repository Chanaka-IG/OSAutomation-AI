# Test Scenarios: My Leave (ESS)

> Feature: An Employee Self-Service (ESS) user views and manages **their own** leave requests at `/leave/viewMyLeaveList` (top-bar tab **"My Leave"**, heading **"My Leave List"**).
> Source: `orangehrm-opensource-domain` (business-rules §1 Auth, §2 Roles, §4 Leave Workflow, §5 Entitlements, §10 Toasts/Loading); user-flows Flow 4. Grounded against the live app (OrangeHRM OS 5.8, `automationtest-os-kord`) on 2026-06-02 as `marcus.chen` (ESS).
> Generated by `/create-scenarios`. Consumed by `/test-strategy`.

Key domain facts (verified live unless noted):
- The search form has: **From Date** (default `2026-01-01`), **To Date** (default `2026-12-31` = current leave period), **Show Leave with Status*** (multi-select, **REQUIRED** — note the `*` and `* Required` hint), and **Leave Type** dropdown. Buttons: **Reset**, **Search**.
- **"Show Leave with Status" is mandatory** — the grid will not search without at least one status selected. Status options: **Rejected, Cancelled, Pending Approval, Scheduled, Taken**.
- Results table columns: ☐ (select) · **Date** · **Employee Name** · **Leave Type** · **Leave Balance (Days)** · **Number of Days** · **Status** · **Comments** · **Actions**.
- This page is **self-only**: there is **no "Employee Name" search field** (unlike Admin/Supervisor `/leave/viewLeaveList`). The Employee Name *column* always shows the logged-in user.
- ESS actions on **own** leave: may **Cancel** an own **Pending Approval** (and **Scheduled**) request; **cannot Approve/Reject own** leave (self-approval is blocked, §4). Terminal states (Cancelled, Rejected, Taken) are read-only.
- Leave status codes: `-1 Rejected, 0 Cancelled, 1 Pending Approval, 2 Scheduled, 3 Taken`. ESS-applied leave enters **Pending Approval**; the pending portion is escrowed from balance immediately (§4).
- `numberOfDays` excludes weekends/holidays per the Work Week (§4). `2026-08-06` is a seeded global holiday.
- Empty result renders **"No Records Found"**. State-changing actions raise a green `.oxd-toast--success`; tables show a shimmer loader (`.oxd-table-loader`) while fetching (§10).
- Seeding note: an ESS account with **no entitlement** shows "No Leave Types with Leave Balance" on Apply and therefore has nothing in My Leave — fixtures must seed an entitlement + at least one request to exercise list/action paths.
