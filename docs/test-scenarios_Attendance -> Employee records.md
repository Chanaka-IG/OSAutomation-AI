## Feature Reference (verified live, 2026-06-14)

### Route
`/web/index.php/attendance/viewAttendanceRecord` — heading **"Employee Attendance Records"** (`<h5>`).
**Admin/supervisor-facing**, read-only (no edit/delete under default config). Two surfaces on one route:

1. **Summary list** (no query string): one row per employee with their total punch duration for the
   selected date.
2. **Employee detail** (`?employeeId=<N>&date=<YYYY-MM-DD>`): that employee's individual punch records
   for the date — same five columns as *My Records*.

### Filter panel (collapsible, toggled by a caret icon-button beside the heading)
- **Employee Name** — optional autocomplete (`Type for hints...`).
- **Date\*** — `input[placeholder="yyyy-mm-dd"]`, defaults to today, **required**.
- **"* Required"** legend + **View** button.
- **View with no employee** → summary list for the date. **View with an employee selected** → navigates to
  that employee's detail (`?employeeId&date`). A row's **View** button does the same for that row's employee.

### Summary list
- Columns: **Employee Name** · **Total Duration (Hours)** · **View** (button).
- `(N) Records Found` counter (N = number of employees listed).

### Detail view (same as My Records grid)
- Columns: **Punch In** · **Punch In Note** · **Punch Out** · **Punch Out Note** · **Duration (Hours)**.
- `(N) Records Found` + no row action affordances under default config.

### API contract (verified)
| Method | Endpoint | Notes |
|---|---|---|
| GET | `/api/v2/attendance/employees/summary?limit=50&offset=0&date=YYYY-MM-DD` | One entry per employee: `{ empNumber, firstName, lastName, middleName, employeeId, terminationId, sum:{hours,minutes,label} }`; `meta.total` = employee count. |
| GET | `/api/v2/attendance/employees/{empNumber}/records?limit=50&offset=0&date=YYYY-MM-DD&empNumber=N` | That employee's punch records; `meta.total` + `meta.sum.label` as in My Records. |

- Punch records are **independent of timesheets** (separate table — domain `business-rules.md` §6).
- ESS users are denied this screen (**"Credential Required"**, verified previously) — it is admin/supervisor scope.
