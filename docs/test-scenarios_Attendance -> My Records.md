## Feature Reference (verified live, 2026-06-14)

### Route
`/web/index.php/attendance/viewMyAttendanceRecord` — heading **"My Attendance Records"** (`<h5>`). A
self-service, **read-only** view of the logged-in employee's punch records for a chosen date.

### Layout
- **Date filter** (collapsible): a calendar/toggle button beside the heading expands a panel with a
  **Date\*** field (`input[placeholder="yyyy-mm-dd"]`, defaults to today), a **"* Required"** legend, and a
  **View** button. Clicking **View** loads records for that date.
- **Summary bar**: `Total Duration (Hours): X.XX` and either `(N) Record(s) Found` or `No Records Found`.
- **Records table** (`.oxd-table-card` rows) with 5 columns:
  `Punch In` (date + time + GMT label) · `Punch In Note` · `Punch Out` (date + time + GMT label) · `Punch Out Note` · `Duration (Hours)`.
- **No action affordances** on rows (no edit/delete/checkbox) under default config (`canUserModifyAttendance=false`).

### Behaviour (verified)
- On page open, records for **today** load automatically.
- Filtering is by the punch-in **`userDate`** (the employee-local date), independent of UTC offset.
- Empty result → `No Records Found`, `Total Duration (Hours): 0.00`, plus an **Info toast "No Records Found"**.
- Clearing the Date and clicking **View** → inline **"Required"** error; results are not refreshed.
- Rows are ordered **newest punch-in first**.
- The page is **self-scoped**: there is **no employee selector** (unlike admin "Employee Records").

### API contract (verified)
| Method | Endpoint | Notes |
|---|---|---|
| GET | `/api/v2/attendance/records?limit=50&offset=0&date=YYYY-MM-DD` | Records for the session employee on `date`. |

Response shape:
```jsonc
{
  "data": [
    { "id": 1,
      "punchIn":  { "userDate":"2026-06-13", "userTime":"17:41", "offset":"5.5", "note":"…"|null },
      "punchOut": { "userDate":"2026-06-13", "userTime":"17:42", "offset":"5.5", "note":"…"|null },
      "duration": "0.02" }
  ],
  "meta": { "total": 18, "sum": { "hours": 0, "minutes": 2, "label": "0.03" } }
}
```
- `meta.total` → the `(N) Records Found` count.
- `meta.sum.label` → the `Total Duration (Hours): X.XX` value.
- Punch records are **independent of timesheets** (separate table — domain `business-rules.md` §6).
- Related guard: `POST /attendance/records` **rejects an explicit past/future date** (`400 "Provided Date And
  Time Invalid"`) while `canUserChangeCurrentTime=false`; the GET/view filter accepts any date.
