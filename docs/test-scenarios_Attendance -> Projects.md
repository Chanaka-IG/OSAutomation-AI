## Feature Reference (verified live, 2026-06-14)

### Routes
| Route | Purpose |
|---|---|
| `/web/index.php/time/viewProjects` | Projects **list** (heading "Projects", `<h5>`). Add button + search filter. |
| `/web/index.php/time/saveProject` | **Add Project** form. |
| `/web/index.php/time/saveProject/{id}` | **Edit Project** form (adds an **Activities** sub-section). |
| `/web/index.php/time/viewCustomers` | Customers list (sibling under Project Info). |

### Add / Edit Project form
- **Name\*** — text.
- **Customer Name\*** — autocomplete (`Type for hints...`) over existing customers, with an inline **Add
  Customer** button → modal (**Name\*** + Description + Save). A project **requires a customer**.
- **Description** — textarea (optional).
- **Project Admin** — employee autocomplete + **Add Another** (zero or more).
- **Save** / **Cancel**; legend **"* Required"** (Name + Customer required).
- Edit page only: **Activities** section with **Copy From** + **Add** (activities are per-project sub-records).

### List
- Columns: **Project** (name) · row actions (**delete** `bi-trash`, **edit** `bi-pencil-fill`) · **Customer Name**.
- `(N) Record(s) Found` / `No Records Found`; a search-filter toggle beside the heading.
- **Delete** → confirm dialog "Are you Sure?" / "The selected record will be permanently deleted…" /
  **No, Cancel** | **Yes, Delete**.

### API contract (verified)
| Method | Endpoint | Body / Result |
|---|---|---|
| GET | `/api/v2/time/projects?limit=50&offset=0&sortField=project.name&sortOrder=ASC&model=detailed` | `{ data:[{ id, name, description, customer:{id,name,deleted}, deleted, projectAdmins:[] }], meta:{total} }` |
| POST | `/api/v2/time/projects` | `{ name, description, customerId, projectAdminsEmpNumbers:[] }` → `{ data:{ id, … } }` |
| DELETE | `/api/v2/time/projects` | `{ ids:[…] }` |
| GET | `/api/v2/time/customers?name=&limit=&offset=` | `{ data:[{ id, name, description, deleted }], meta:{total} }` |
| POST | `/api/v2/time/customers` | `{ name, description }` → `{ data:{ id, name, description, deleted } }` |

### Behaviour (verified)
- Saving a project redirects to the edit page `/time/saveProject/{id}` (standard OXD save → "Successfully Saved").
- Inline-added customer is auto-selected into the project's Customer field.
- **Admin-only**: ESS users get **"Credential Required"** on `/time/viewProjects` (the Time menu is visible
  but Project Info is privileged).
- Projects/timesheets relationship: projects + activities are the catalog timesheets log time against
  (domain `business-rules.md` §6/§7 — Time module).
