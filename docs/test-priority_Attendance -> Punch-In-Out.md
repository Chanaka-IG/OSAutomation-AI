## P0 — Release-blocking (core flow, security, data integrity, no workaround)

| ID | Scenario | Rationale |
|---|---|---|
| TC-001 | Punch In at current time | The single most-used action of the feature. If punch-in fails, the module is unusable. Core flow, no workaround. |
| TC-003 | Punch Out closes the open record | Other half of the core cycle; a stuck "punched in" state corrupts attendance data. |
| TC-004 | Full cycle → exactly one record in My Records | End-to-end data integrity: the user's worked time must be recorded and visible. The product's whole purpose. |
| TC-100 | Cannot Punch In twice (already-in redirect) | State-machine invariant; a second open record corrupts the ledger. No user workaround. |
| TC-201 | ESS user cannot access Attendance Configuration | Authorization/compliance — an employee must not flip global attendance policy. |
| TC-202 | ESS user cannot access Employee Records | Privacy/compliance — an employee must not see colleagues' attendance. |

## P1 — High impact (primary path, high reach, major integration)

| ID | Scenario | Rationale |
|---|---|---|
| TC-002 | Punch-in note persists onto Punch Out screen | Primary feature path; notes are a headline capability of punch and feed records. |
| TC-101 | Cannot Punch Out when not punched in | Complementary guard to TC-100; protects against orphan punch-outs. |
| TC-005 | My Records shows total duration + record count | High reach — every employee reads this; wrong totals erode trust in payroll-adjacent data. |
| TC-102 | Date/Time disabled when `canUserChangeCurrentTime=false` | Default-config behaviour every user hits; guarantees punches use real server time. |
| TC-500 | Correct heading & action button per state | The user's only cue to current state; wrong label → wrong action. High reach, primary UX. |
| TC-502 | Punch Out screen shows read-only punched-in summary | Primary-path context the user relies on before punching out. |
| TC-205 | Unauthenticated access redirects to login | Security baseline for all attendance routes; high blast radius if broken. |
